# 電視壁掛架掛勾喇叭籃　建模規劃

## 需求（使用者提供，實測值）

| 項目 | 值 |
|------|-----|
| 兩孔中心間距 | 200 mm |
| 橢圓孔尺寸 | 寬 8.3 × 高 19.8 mm（長軸垂直） |
| 角鋼面 ↔ 電視背面 間距 | 8.6 mm（懸掛結構厚度上限） |
| 喇叭 | 長 200 × 深 50 × 高 70 mm |
| 掛鉤下延長度 | 約 40 mm |
| 籃子開放面 | 上方全開、前方開放（底部留淺擋板） |

## 座標系定義

- **X**：水平（電視左右），0 = 兩掛鉤中點，掛鉤在 X = ±100
- **Y**：深度，0 = 角鋼沖孔面（= 背板貼合面），+Y = 朝觀眾（電視方向）
- **Z**：垂直，0 = 橢圓孔「下緣」（掛鉤承重點），+Z 向上

## 設計決策

1. **掛鉤形式**：舌片穿孔 → 孔後下折的 L 形勾。
   - 舌片寬 7.4（< 孔寬 8.3）、厚 4，下折 12 → 插入高度 16 < 孔高 19.8 ✅
   - 舌片與下折間留 3.0 溝槽容納角鋼板厚（實際 1.5~2.0，餘裕不影響）
2. **抗前傾**：背板整片貼在角鋼面上（Y=0），下方受角鋼面頂住，上方由下折勾住角鋼背面，形成力偶。實測餘隙 1mm ÷ 108mm 力臂 → 傾角 0.5°，可忽略。
3. **厚度限制**：背板厚 4.0 mm（< 8.6，留 4.6 mm 對電視餘裕），掛鉤在角鋼面前方也只到 Y=+4。
4. **列印方向**：以籃底朝下直立列印（如懸掛姿態）。
   - 底部為 214 × 64 實心平面 → 附著佳、無橋接
   - 全部牆體垂直向上 → 零懸空
   - 僅兩個下折勾（各 7.4 × 3 × 12）需要支撐，切片器自動處理

## 主要尺寸推導

- 內腔 206（長）× 56（深）× 70（高）　＝ 喇叭 + 6mm 總餘裕
- 外形 214（寬）× 64（深）× 120（高，Z = +6 ~ −114）
- 前擋板高 12 mm（籃底面起算）
- 籃口 Z = −40（掛鉤下延 40mm 後開始）

## Review — v2（背板減重凹槽 + 切片預設）

### 使用者需求

「掛鉤那一面的板子，中間掛鉤中間的區塊應該可以省掉」「設計成凹下去，
只要注意不要影響到掛鉤的強度」；另外釐清先前問的「參數」是指**切片軟體參數**，
要求直接寫進去。

### 做了什麼

1. **CAD**：`build_basket.py` 新增背板減重凹槽（3 個參數 + 3 個 assert + 1 道 cut）。
   做盲孔不做穿透窗——Y=0 那面要貼合角鋼、承受抗前傾力偶，必須保持完整平面，
   所以只從 +Y（電視側）挖進去留 1.2mm 蒙皮。
2. **切片**：寫入 Bambu Studio 使用者預設 `TV喇叭籃 0.20 支撐`
   （A1 0.4 噴頭 / PETG Basic，繼承 `0.20mm Standard @BBL A1`），34 個參數。
3. 順手修掉腳本裡寫死的 PLA 密度（實際用 PETG），報表數字才是對的。

### 量測結果（`cad/verify_v2.txt`）

| 項目 | 預期值 | 實測值 | 通過 |
|------|--------|--------|------|
| BoundBox X / Y / Z | 214 / 70 / 120（不變） | 214.00 / 70.00 / 120.00 | ✅ |
| Solids | 1 | 1 | ✅ |
| isValid / isClosed | True / True | True / True | ✅ |
| Faces / Edges | — | 37 / 96（v1 為 32 / 84） | — |
| Volume | < v1 的 198 422.7 | 183 190.7 mm³ | ✅ |
| 相對 v1 減重 | — | **−15 232 mm³（−7.7%）** | ✅ |
| 凹槽 | 160 × 34 × 2.8 深 | 同左，殘留壁厚 1.2 | ✅ |
| 掛鉤兩側實心帶 | — | 27mm × 4.0 ×2，剪力面積 216 mm² | ✅ |
| VERIFY | PASS | PASS | ✅ |

強度確認：載重（籃 + 喇叭）約 9.1N 走兩側實心帶 → 0.04 MPa，對 PETG 是三個數量級餘裕。

### 目視驗證

`v2_front.png` 可見凹槽矩形（X ±80、Z −34~0），掛鉤（X ±100）未被切到；
`v2_top.png` 可見 Y=1.2 的凹槽底面線，X ±80 以外仍是完整 0~4 背板；
`v2_iso.png` 可見背板中央凹陷。

### 這次學到的

1. **省料的大頭是切片不是 CAD**：183 191 mm³ 是 100% 實心的數字，
   3 圈牆 + 12% gyroid 之後實際大約只有一半。凹槽只佔 7.7%。
2. **FreeCAD MCP 卡死找到成因**：GUI 裡有 **Measure 工具還開著**會擋住 dispatch，
   `Control.closeDialog()` + `resetEdit()` 可解。不是進程壞掉。
3. **Bambu Studio CLI 在 GUI 已開啟時完全不能用**：`--slice` 把啟動交給既有實例，
   不輸出、不回 exit code、不產檔。要 CLI 切片必須先完全關閉 Studio。

## Review — v3（背板改鏤空、上緣不封）

### 使用者需求

「直接改成鏤空的，不是凹下去而已，直接把它改成空的，沒有塑膠。不要懸空，
包含上面那些都不要懸空，不然會多出支撐件。」

### 做了什麼

把 v2 的盲孔凹槽改成**貫穿開窗**，並且**上緣不封**（切超過件頂）。
`BP_SKIN` 參數整個移除，`BP_KEEP_Z` 改成只管下緣的 `BP_KEEP_BOT`。
背板因此變成 U 形：兩根 27mm 寬 × 4mm 厚實心帶各扛一個掛鉤，
窗下緣 6mm 橫帶（Z −40~−34）把兩側綁回籃體。

順手在 `render_views.py` 加了朝下面稽核，直接量出哪些面會長支撐。

### 量測結果（`cad/verify_v3.txt`）

| 項目 | 預期值 | 實測值 | 通過 |
|------|--------|--------|------|
| BoundBox X / Y / Z | 214 / 70 / 120（不變） | 214.00 / 70.00 / 120.00 | ✅ |
| Solids / isValid / isClosed | 1 / True / True | 1 / True / True | ✅ |
| Faces / Edges | — | 36 / 96 | — |
| Volume | < v2 的 183 190.7 | 172 822.7 mm³ | ✅ |
| 相對 v1 減重 | — | **−25 600 mm³（−12.9%）** | ✅ |
| 鏤空 | 160 × 40 貫穿 4.0 | 同左，上緣開放 | ✅ |
| 掛鉤兩側實心帶 | — | 27mm × 4.0 ×2，剪力面積 216 mm² | ✅ |
| VERIFY | PASS | PASS | ✅ |

### 懸空稽核（v2 vs v3，同一支腳本量的）

| Z | v2 | v3 | 說明 |
|---|----|----|------|
| −114.0 | 13 696 mm² | 13 696 mm² | 貼平台，非懸空 |
| −12.0 | 22.2 mm² | 22.2 mm² | ★兩個下折勾底面，真孤島，避不掉 |
| −11.5 / −11.0 | 31.4 mm² | 31.4 mm² | 45° 倒角，可自撐 |
| 0.0 | **470.2 mm²** | **44.4 mm²** | v2 多的 448 mm² 就是凹槽頂緣（160 × 2.8）|
| **真需支撐合計** | **514.6 mm²** | **66.6 mm²** | −87% |

v3 剩下的 44.4 mm² 是掛鉤舌片跨過 3mm 溝槽的短橋接，可以橋接不必支撐。

### 這次學到的

1. **凹槽 vs 鏤空的差別不在省料，在懸空**：v2→v3 只多省 10 368 mm³（5%），
   但把水平懸空面從 470 mm² 砍到 44 mm²。使用者的直覺是對的。
2. **下折勾的支撐避不掉**：勾的外腿正下方（Y<0）全空，是離平台 102mm 的孤島；
   想加斜撐接回背板，斜撐會落在角鋼立柱本體的位置，會撞到。
3. **FreeCAD MCP timeout 成因確定**：GUI 的 Measure 工具啟用中就會擋住 dispatch，
   使用者正在量尺寸時必撞。另外 `setViewDirection()` 實測兩次必 timeout，不要用。
